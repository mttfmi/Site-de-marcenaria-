# 🪵 Site: Marcenaria do Carlito

Site institucional responsivo para uma marcenaria de São Gonçalo (RJ), com formulário de orçamento integrado ao **Firebase**.

## Funcionalidades

- **Página única** com seções Sobre, Serviços e Contato
- **Layout responsivo** com menu adaptado para celular
- **Cards de serviços**: cadeiras, mesas, armários e outros móveis sob medida
- **Formulário de orçamento** com nome, telefone, e-mail, tipo de serviço e mensagem
- **Integração com Firebase** para armazenar as mensagens enviadas
- Botão de contato direto pelo WhatsApp

## Tecnologias

HTML5 · CSS3 · JavaScript · Firebase · Google Fonts · Font Awesome

## Como visualizar

Basta abrir o arquivo `index.html` no navegador.

## Sobre o desenvolvimento

Projeto de teste para praticar a integração de um site com banco de dados na nuvem (Firebase), usando ferramentas de IA para acelerar a criação do layout.
